# DriveOra API

Backend API for DriveOra, a car rental platform that allows users to browse vehicles, manage bookings, and securely authenticate.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt
- CORS
- dotenv

## Features

- User authentication and authorization
- Car/vehicle management
- Car rental bookings
- Booking management
- Secure password hashing
- JWT-based authentication
- RESTful API endpoints

## Getting Started

### Installation

```bash
git clone https://github.com/calebtolorunleke/DriveOra_api.git
cd DriveOra_api
npm install

Environment Variables

Create a .env file:

PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
Run the Server

Development:

npm run dev

Production:

npm start
Project Status

🚧 Currently under development.
```
